# 逻辑星球

面向 9–12 岁孩子的网页数理逻辑训练游戏。题目采用探索任务、密码破解、路线规划和策略实验等形式，不依赖校内教材章节。

## 本地运行

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 <http://localhost:4173>。

## 当前内容

- 按 9、10、11、12 岁分层调整题目难度
- 规律识别、密码推理、路线规划三类任务
- 出舱规划、双条件分类、逆推取石三种互动实验
- 分层提示、即时解释和本地进度保存
- 响应式布局与键盘可操作界面

玩法研究与原创转化记录见 [docs/game-research.md](docs/game-research.md)。项目只借鉴通用机制，不复制第三方题目、代码、名称或美术素材。
